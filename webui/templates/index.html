三步上手

  1. 填题材：一句话描述你要写什么，例如「RabbitMQ 入门：同步调用与异步调用」。
  2. 给材料（可选）：点「选笔记文件」传 .md/.txt，或点「选截图目录」传课程截图。 有材料会自动判成课程笔记文，没有就按知识点文写。也可以直接把路径粘进输入框按回车。
  3. 加入队列：点按钮提交，任务在后台依次跑。日志实时滚动，跑完可以查看文章或打开输出文件夹。

四种文章类型

不选就用「自动」：带材料判成课程笔记文，不带材料判成知识点文。

知识点文
围绕一个概念、机制、注解、API 或报错讲透。按使用场景 → 核心概念 → 最小代码 → 执行流程 → 常见坑与排查 → 验证方式组织。
课程笔记文
以你给的笔记和截图内容为边界展开，一级知识点保持材料里的顺序，材料里没有的主题不写。
项目功能文
围绕一个功能走完整闭环：功能目标 → 接口与入参 → Service 处理 → 持久化 → 验证与常见失败点。

选项说明

先确认大纲
写完大纲先停下来，等你在页面上点「继续写正文」或「取消」。 默认 600 秒不确认就自动取消。注意：队列是顺序执行的，一篇卡在确认上，后面的任务也会一起等。
跳过大纲
不先出大纲，直接写正文，快一点但结构可能差一些。
跳过去 AI 味
不改写，直接输出初稿，方便你看模型原本的表达。
跳过自检
不做交付前检查。自检会数格式标记、量前言长度、扫禁用句式，不合格自动回喂重写一次。

队列与取消

  • 可以连续提交多篇，后台顺序执行，不会同时写两篇。
  • 取消在阶段边界生效：正在飞的模型调用中断不了，点了取消要等当前阶段跑完；排队中的任务立刻取消。
  • 关掉页面不影响已经提交的任务，它会在后台跑完。重新打开页面任务还在列表里。
  • 同名同日的文章不会互相覆盖，第二个会自动加 -2 后缀。

每篇会产出什么

输出在 output/ 下的一级目录里：

index.md
最终文章，可以直接复制到 CSDN。
selfcheck.md
交付前自检报告：格式标记数量、前言字数、命中的问题。
humanize_changes.md
去 AI 味阶段改了什么。
outline.md
大纲和插图计划，含封面建议。

配图怎么办

当前是手动配图模式，不自动出图。文章里每个插图位置会留一条配图建议： 

> 📷 **配图建议：** 同步调用链路示意，从支付服务依次串起用户服务、交易服务……
> *（请手动配图）*

照着描述找图或截图，把引用块替换成 ![说明](图片文件名) 即可。 想改成自动出图，改 config.yaml 里的 image.provider。

习惯命令行的话

网页界面和命令行共用同一套流水线，效果一样。

python run.py "RabbitMQ 入门" -m ./笔记.md -m ./截图目录 --review
python run.py "Redis 为什么快" --fast --no-images
