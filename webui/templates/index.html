    使用说明
    
        
      
          
    1. 填题材：一句话描述你要写什么。
      2. 
          
    2. 给材料（可选）：点「选笔记文件」传 .md/.txt，或点「选截图目录」传课程截图。
            有材料会自动判成课程笔记文，没有就按知识点文写。
      3. 
          
    3. 加入队列：任务在后台依次跑，日志实时滚动。
      4. 
        
    
        
    
          
    先确认大纲
    
          
    写完大纲先停下来，等你在页面上点「继续写正文」或「取消」。队列是顺序执行的，一篇卡在确认上，后面的任务也会一起等。
    
          
    跳过大纲
    
          
    不先出大纲，直接写正文，快一点但结构可能差一些。
    
          
    跳过去 AI 味 / 跳过自检 / 跳过插图 / 跳过封面提示词
    
          
    分别跳过对应阶段。跳过自检意味着不做格式门禁检查；跳过封面提示词则不产出封面提示词文件。
    
        
    
        
      
          
    • 可以连续提交多篇，后台顺序执行，不会同时写两篇。
      • 
          
    • 取消在阶段边界生效：正在飞的模型调用中断不了，点了取消要等当前阶段跑完。
      • 
          
    • 关掉页面不影响已经提交的任务。同名同日的文章不会互相覆盖，第二个自动加 -2 后缀。
      • 
        
    
      
    

      
    
        
    每篇产出什么
    
        
    输出在 output/ 下的一级目录里：
    
        
    
          
    index.md
    
          
    最终文章。
    
          
    自检报告 / 去 AI 味改动 / 大纲
    
          
    分别是 selfcheck.md、humanize_changes.md、outline.md。
    
          
    标题.cover_prompt.md
    
          
    封面提示词（含风格选择依据、可直接复制的提示词、质量检查结论）。
    
        
    
      
    

      
    
        
    配图怎么办
    
        
    当前是手动配图模式，不自动出图。文章里每个插图位置会留一条配图建议：
    
        
    > 📷 **配图建议：** 同步调用链路示意，从支付服务依次串起用户服务、交易服务……
> *（请手动配图）*
    
        
    
          照着描述找图或截图，把引用块替换成 ![说明](图片文件名) 即可。
          封面同理：复制封面提示词到出图工具生成，再放进文章目录。
        
    
      
    

      
    
        
    习惯命令行的话
    
        
    网页界面和命令行共用同一套流水线，效果一样。
    
        
    python run.py "RabbitMQ 入门" -m ./笔记.md -m ./截图目录 --review
python run.py "Redis 为什么快" --fast --no-images
